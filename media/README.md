# الفيلم ومصدر إعادة تركيبه

[شاهد النسخة النهائية](https://islamicaich.salsabeel.ai/beta/2-5/): بيتا ٢٫٥، مراجعة R10، 118 ثانية، 1920×1080، 24 إطارًا/ثانية. المشغّل يتضمن الموسيقى تشغيلًا وإيقافًا، فصولًا وأسئلة قابلة للنسخ، وروابط البحث والمصادر.

الملفان النهائيان في `app/public/beta/2-5/`، والبصمات في [release.json](release.json). [التوقيت](timeline.json) و[النص المشكول](Narration_AR.txt) و[حقوق الموسيقى](MUSIC_CREDITS.txt) مرفقة.

## مصدر آمن قابل لإعادة التركيب

`source/picture.mp4` أصل الصورة المركّبة بلا صوت، و`source/voice.flac` أصل التعليق المعتمد، و`source/music-mix.flac` المزيج المعتمد. هذه أصول تحرير مسطّحة للمراجعة وإعادة تركيب نسختي الفيلم؛ لا ندّعي أنها مشروع طبقات الرسوم الأصلي الكامل.

ثبّت FFmpeg وPython 3، ثم من جذر المستودع:

```sh
python media/rebuild.py
```

ينتج مجلد `media/output/` نسختين. نسخ مسار الصورة يحافظ عليه، وقد تختلف بصمة الحاوية أو ترميز الصوت باختلاف إصدار FFmpeg. لا يتطلب ذلك مفاتيح TTS أو بيانات المصنع. النص والتوقيت يسمحان بتحرير نسخة جديدة مع حفظ حقوق الأصول.

المتجاور 81–89 ثانية، قبل الفرائض 89–95؛ مشهد العلماء محفوظ. المعمارية في الفيلم شرح تصميمي، وليست تتبعًا حيًا لكل طلب.
