# الفيلم ومصدر إعادة تركيبه

[شاهد مراجعة المجلس R12](https://islamicaich.salsabeel.ai/beta/2-5/?v=12): **١١٨ ثانية**، 1920×1080، 24 إطارًا/ثانية. نسختان للصوت؛ زر الموسيقى في الزاوية العليا يحفظ موضع المشاهدة عند التبديل.

في ٦ أكتوبر حُدّث سؤال الكعبة بلقطة فعلية من المجلس ومصدر مفتوح، والمعمارية بحسب الشخصيات، وشريحة NMN برقم الطلب SA 1020268774. ومن ٩٥ إلى ١١٢ ثانية نعرض اختيار الشخصية، كتابة السؤال أو اختيار سؤال جاهز، ثم مصادر الجواب. المقدمة والعلماء محفوظان؛ عينات صوت الراوي خارج المقطع الجديد مطابقة للأصل المعتمد. اكتمال المراجعة الآلية ليس شهادة بصحة كل عبارة.

**حدود الأمثلة:** مشاهد الاشتقاقات (٤٩–٦١)، استكمال الآية (٧٢–٨١)، التجاور (٨١–٨٩) والمواريث (٨٩–٩٥) أدلة سابقة من ٤–٥ أكتوبر. تثبت عيناتها وأدواتها المسجلة، ولا تمثّل واجهة المجلس الجديدة أو إعادة اختبار كاملة عليها. التجاور يسبق الفرائض. المعمارية شرح تصميمي وليست تتبعًا حيًا لطلب بعينه. الأصل التصويري للمواريث أُعيد تنسيقه للعرض.

البصمات في [release.json](release.json)، والتحقق في [r12-verification.json](r12-verification.json)، والتوقيت في [timeline.json](timeline.json)، والنص المشكول في [Narration_AR.txt](Narration_AR.txt)، و[حقوق الموسيقى](MUSIC_CREDITS.txt). سجل R11 محفوظ بوصفه سجلًا تاريخيًا للإصدار السابق.

## أصول آمنة قابلة لإعادة التركيب

`source/picture.mp4` الصورة المركبة بلا صوت؛ `source/voice.flac` أصل الراوي؛ `source/music-mix.flac` المزيج المعتمد. هي أصول تحرير مسطحة، وليست مشروع طبقات الرسوم الكامل أو كود تصنيع النموذج.

بعد تثبيت Python 3 وFFmpeg، من جذر المستودع:

```sh
python media/rebuild.py
```

ينتج `media/output/` نسختَي الفيلم. لا يلزم مفتاح صوت أو بيانات مصنع. يبقى مسار الصورة محفوظًا بالنسخ، وقد تختلف بصمة الحاوية أو الصوت باختلاف إصدار FFmpeg.
