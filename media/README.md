# الفيلم ومصدر إعادة تركيبه

[شاهد مراجعة المجلس R15](https://islamicaich.salsabeel.ai/final/): **١١٨ ثانية**، 1920×1080، 24 إطارًا/ثانية. نسختان للصوت؛ زر الموسيقى في الزاوية العليا يحفظ موضع المشاهدة عند التبديل.

جميع مشاهد التطبيق من المجلس الحالي في ٦ أكتوبر: سؤال الكعبة ومصدره، شواهد رشيد ومرشد، استكمال الآية، التجاور، المواريث، واختيار الشخصية وكتابة السؤال وفتح المصادر. المقدمة والعلماء محفوظان، ومسارا الصوت مطابقان بايتًا للإصدار المعتمد R12. لا تغيير في النطق أو الموسيقى.

**حدود الأمثلة:** اللقطات توثق عينات مختارة. مشهد الاشتقاق يثبت فتح ثلاثة شواهد لرشيد في هود٧٨ و٨٧ و٩٧، وشاهد لمرشد في الكهف١٧؛ لا يعتمد الأوزان الصرفية الأخرى في الجواب. مشهد التجاور يخص القرائن الإحصائية، لا كامل التحليل اللغوي. المواريث مسألة تعليمية بمعطيات محددة، وصورتها لقطة فعلية واسعة من الموقع. المعمارية شرح تصميمي وليست تتبعًا حيًا لطلب بعينه.

البصمات في [release.json](release.json)، والتحقق في [r15-verification.json](r15-verification.json)، والتوقيت في [timeline.json](timeline.json)، والنص المشكول في [Narration_AR.txt](Narration_AR.txt)، و[حقوق الموسيقى](MUSIC_CREDITS.txt). سجلات R11 وR12 وR13 وR14 محفوظة بوصفها سجلات تاريخية.

طابقت مراجعة R14 ألوان الإطارات والبطاقات والمعمارية المؤلفة من الثانية ٢٢ إلى ١١٢ مع الموقع الحالي. بقيت صور الأدلة دون إعادة تلوين، وحُفظت المقدمة والعلماء والخاتمة المعتمدة. طُوبقت صفحة المشاهدة وصورة غلافها أيضًا؛ لا تغيير في التوقيت أو التعليق الصوتي.

راجعت نسخة R15 مشهد العلماء من ٠:١٠ إلى ٠:٢٢: طُوبقت ألوان شريطي العنوان والتعليق مع الهوية الحالية، مع حفظ الرسم الأصلي وتسلسل المعلومات. بقي الصوت والتوقيت معتمدين دون إعادة نطق.

## أصول آمنة قابلة لإعادة التركيب

`source/picture.mp4` الصورة المركبة بلا صوت؛ `source/voice.flac` أصل الراوي؛ `source/music-mix.flac` المزيج المعتمد. هي أصول تحرير مسطحة، وليست مشروع طبقات الرسوم الكامل أو كود تصنيع النموذج.

بعد تثبيت Python3 وFFmpeg، من جذر المستودع:

```sh
python media/rebuild.py
```

ينتج `media/output/` نسختَي الفيلم. لا يلزم مفتاح صوت أو بيانات مصنع. يبقى مسار الصورة محفوظًا بالنسخ، وقد تختلف بصمة الحاوية أو الصوت باختلاف إصدار FFmpeg.
