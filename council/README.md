# مجلس سلسبيل — كود الواجهة العامة

**الفتى ولينة وقبس يعملون على [المجلس الحي](https://islamicaich.salsabeel.ai/).** هذا المجلد يتيح مراجعة كود الواجهة المطابق للإصدار `comparison-contract-20261007` المفعّل في ٧ أكتوبر، مع خادم معاينة محلي مستقل بلا مفاتيح ولا اتصالات بمزوّد النموذج. تطابق الأصول لا يعني صحة جميع الإجابات؛ انظر [سجل الحالة والحدود](../docs/STATUS_20261007_AR.md).

```sh
cd council
npm start
```

افتح `http://127.0.0.1:8793`. لا يحتاج التشغيل المحلي إلى تثبيت حزم. يتطلب Node.js 22 أو أحدث. اختيار الشخصيات واستعراض الأسئلة يعملان في المعاينة؛ **توليد الإجابات وقارئات النصوص يحتاجان الخدمة الحية**. المعاينة تعيد خطأ واضحًا عند استدعاء API؛ لا تختلق نجاحًا أو جوابًا.

| أين تجد العمل؟ | النطاق |
|---|---|
| `public/app.js` و`index.html` و`style.css` | الشخصيات الثلاث، الاقتراحات، استقلال المحادثات وعرض المصادر والمراجعة |
| `public/stream-ui.js` | قراءة البث وعرض النص أثناء وصوله والتعامل مع الانقطاع |
| `public/handoffs.js` | انتقال المستخدم من بطاقات الفتى المعروفة بالسؤال المرتبط بها |
| `public/hadith-identity.js` و`hadith-renderer.js` | عرض إحالات الحديث المربوطة بالسجل وقارئه |
| `public/internal-renderer.js` | عرض المقاطع المسترجعة فعليًا من المصادر الداخلية؛ يميّز مقتطف التفسير وإحصاءات الجذور عن النص الكامل |
| `public/genesis.js` و`genesis.css` | حزمة العرض المشتركة الموجودة أصلًا؛ ليست أوزانًا أو محرك استدلال |
| `provenance.json` | بصمة كل أصل وعلاقته بالنسخة المثبتة |
| `application/request-queue.mjs` | كود الطابور المستخدم في الإنتاج: ترتيب الطلبات، السعة، المهلة والإلغاء |
| `application/provider-errors.mjs` | كود تصنيف أخطاء المزوّد وتنقية بياناتها؛ لا يتضمن مفاتيح أو ربطًا بنموذج |
| `preview.mjs` و`test/` | معاينة محلية واختبار منع نشر ملفات أو إجابات غير موجودة |

مصدر حزمة العرض المشتركة موجود في [`app/src/genesis`](../app/src/genesis/) وإصدارات حزمها في [`app/package-lock.json`](../app/package-lock.json). لم ننسب هذا المكوّن السابق إلى إنجاز التحدي الجديد. إشعارات اعتماديات npm محفوظة في [`licenses`](licenses/). وإشعار LibreChat محفوظ مستقلًا للمكونات التي ينطبق عليها؛ وجوده لا ينسب ملفات عرض سلسبيل المخصصة إلى LibreChat، ولا يعني أن تطبيق المجلس المستقل هو تطبيق LibreChat.

نفّذ `npm test` و`npm run check` لفحص هذا التصدير. هذه الفحوص تخص سلامة مواد الواجهة وحدود المعاينة، وليست اختبارًا لصحة الأجوبة.

الوحدتان في `application/` مطابقتان للنسخة المثبتة دون تعديل، وتصحبهما اختبارات قائمة. اختبار الطابور مطابق كذلك؛ أما اختبار أخطاء المزوّد فيحتفظ بالاختبارات المستقلة فقط، ويحذف اختبارات التكامل التي تستلزم تشغيل المنظومة الخاصة. التغييرات وبصمات الأصل والتصدير مسجلة صراحة في بيان المصدر. جميع بيانات الاعتماد المذكورة في الاختبارات مصطنعة للتحقق من التنقيح، وليست مفاتيح صالحة.

**حدود التسليم:** لا يتضمن هذا المجلد خادم الاستدلال الإنتاجي ولا تعليمات الشخصيات الخاصة ولا أدوات المصنع ولا الأوزان ولا كامل RAG/SFT. لينة وقبس متاحان لتجربة التحدي، وواجهتاهما لعموم المطورين غير معلنتين كخدمة متاحة بعد. انظر [حدود كود المجلس](../docs/COUNCIL_SOURCE_AR.md)، [عقد الواجهة](../docs/API_AR.md)، و[التشغيل](../docs/SETUP_AR.md).
