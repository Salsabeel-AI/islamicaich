# تطبيق المحادثة الإسلامية

ابدأ من [README الرئيسي](../README.md) و[دليل الإعداد](../docs/SETUP_AR.md).

المصدر الحالي من تطبيق التحدّي، مع تحويل استيراد اختبار واحد إلى مسار نسبي وتنقيح بيانات المنشأ. لا توجد إجابات تجريبية مزروعة في الخادم الإنتاجي. `tests/ui-preview.mjs` معاينة اختبارية منفصلة فقط، وليست خدمة الإجابات.

تُرفق ملفات العرض المبنية لتعمل `npm start` مباشرة بعد `npm ci`. لإعادة بناء واجهة React: `npm run build:presentation`.
