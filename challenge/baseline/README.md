# خط الأساس المتاح للفحص

هذه نسخة منتقاة من لقطة التطبيق المؤرخة ٤ أكتوبر. أصبح الكود نفسه متاحًا للمقارنة بدل الاكتفاء ببصمة أرشيف غير منشور. [الجرد](manifest.json) يربط كل ملف بمحتواه داخل الأرشيف وبنسخته المنشورة، ويصرّح بالتنقيح أو اختلاف نهايات الأسطر.

قارن `challenge/baseline/app` مع `app` بواسطة `python scripts/compare_baseline.py`. هذا يقيس فرق التطبيق، ولا ينسب كل مكوّن سابق من سلسبيل إلى أيام التحدّي. ملفات النسب الخاصة والتغليف مستبعدة؛ ساعة بداية التحدّي لا تُستنتج من اسم الملف وحده. استخدم التطبيق الحالي للتشغيل، وهذه النسخة للفحص التاريخي.
