# خطة التشغيل والاستكمال

## الاعتمادات والمسؤوليات

| المسؤولية | الدور المقترح | الدليل أو الإجراء |
|---|---|---|
| التطبيق وإدارة الإصدارات | مسؤول تطبيق المشاركة | حفظ نسخة مستقرة ومقارنة التغييرات وتشغيل الاختبارات |
| الخدمة والمفتاح والحصة | مسؤول حساب سلسبيل والمزود | مراجعة الاستحقاق والمفتاح وانشغال الحساب قبل يوم العرض |
| صحة النقل وحدود الفتوى | مراجع محتوى مؤهل تسميه الجهة | مراجعة الحالات الحرجة ثم عينات دورية بعد كل تحديث |
| الأدلة ومواد التحكيم | مسؤول التسليم | ربط كل ادعاء بإصدار ونتيجة ولقطة وتحديث سجل القيود |

هذه مسؤوليات خطة تشغيل؛ لا نزعم وجود اتفاقية خدمة أو تعيين مختص لم يُثبت بعد.

## تكلفة قابلة للحساب

التكلفة الشهرية = استضافة التطبيق + تكلفة طلبات API + ساعات مراجعة المحتوى × تكلفة الساعة + احتياطي التشغيل. [المدخلات](../operations/cost-model.json) تميّز المقاس من غير المتاح. لا تتضمن الحزمة تسعيرًا تعاقديًا لم يقدمه المزود.

نقيس من السجل المنشور 50 طلبًا تاريخيًا مكتملًا ووسيط زمن 9.16 ثانية للنسخة اللاحقة؛ هذا لا يحدد تكلفة الطلب ولا السعة المتزامنة ولا زمن الذروة. مثال ميزانية تخطيطي فقط: 10,000 طلب × 0.05 ريال + 150 ريال استضافة + 8 ساعات × 100 ريال = 1,450 ريال شهريًا قبل الاحتياطي والضريبة. **كل الأسعار وعدد الساعات هنا افتراضات تخطيطية وليست فاتورة أو عرض سعر أو قياسًا فعليًا**. قبل التبني تستبدل ببيانات الحساب والفاتورة وتجربة المستفيدين.

## الاستمرارية عند التعطل

1. عرض خطأ واضح وإعادة المحاولة بنفس هوية الطلب، دون اختلاق جواب بديل.
2. الاحتفاظ بالفيديو والعرض والروابط المباشرة للمصادر كمسار اطلاع مستقل عن الإجابات الحية؛ تحميل PDF مسبقًا يتيح العرض دون اتصال.
3. يفحص مسؤول التشغيل الحالة والمفتاح والحصة. عند تكرار الفشل يوقف إعادة المحاولات المزعجة، ويوجّه المستخدم للمصدر أو الجهة المختصة.
4. الرجوع إلى آخر نسخة تطبيق اجتازت الاختبارات عند خلل الواجهة. رجوع إصدار خدمة المزود يحتاج إجراء المزود؛ هذا المستودع لا يتحكم في أوزانه.

هذا بديل للوصول إلى المادة والمصدر، لا نموذج احتياطي يولّد إجابات مكافئة. لا توجد ضمانة SLA أو سعة مؤكدة مرفقة.

## تبنٍّ تدريجي

تجربة بإشراف مراجع وفئة مستفيدة صغيرة؛ قياس إتمام المهمة وفتح الدليل وفهم الجواب؛ مراجعة أسبوعية للحالات المرفوضة والخاطئة؛ ثم توسيع الاستخدام بعد اجتياز بوابات القبول. تُراجع المصادر عند تغير حقوقها أو محتواها، وتُزال المادة التي لا يثبت حق استخدامها. تبقى المحادثات وسجلات الزوار خارج مستودع التسليم.
