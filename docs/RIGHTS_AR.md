# الحقوق والمصادر

إتاحة مستودع للفحص لا تمنح تلقائيًا حقوق جميع أصول سلسبيل. مكونات سلسبيل الأصلية محفوظة الحقوق ما لم يُذكر خلاف ذلك. تبقى تراخيص المكونات الخارجية سارية. لم تُمنح رخصة مفتوحة عامة لأوزان أو بيانات أو مصنع المزود.

| المادة | المنشأ والحدود |
|---|---|
| تطبيق التحدّي ووثائق التسليم | إعداد سلسبيل للمشاركة؛ محفوظة الحقوق؛ متاحة للفحص المصرح به |
| عناصر عرض GenesisChat | عناصر عرض سابقة أعيد استخدامها؛ بيانات النسب المنقّحة في `app/src/genesis/provenance.json`. إشعار LibreChat MIT محفوظ في `licenses/LibreChat-MIT.txt` للمكونات التي ينطبق عليها |
| حزم npm | إصدارات مقفلة في `app/package-lock.json`، وتراخيص الحزم تبقى معها |
| خط Readex Pro | SIL Open Font License؛ انظر `licenses/ReadexPro-OFL.txt` |
| شعارات سلسبيل والتحدّي | علامات أصحابها؛ عرضها للتعريف بالمشاركة لا يمنح ترخيص علامة تجارية |
| صور الواجهة | لقطات اختبارات مصطنعة يملكها فريق المشاركة؛ النصوص المرجعية الظاهرة تظل لأصحابها |
| النصوص الإسلامية الخارجية | روابط وبيانات وصفية ولقطات محدودة؛ لا توزيع كامل للمدونات ولا ادعاء ملكية تحريرها |
| الموسيقى | The Desert / The Grand Score — Alexander Nakarada (CreatorChords)، CC BY 4.0، مع الاقتطاع والتدرج وخفض المستوى؛ النسبة الكاملة في `media/MUSIC_CREDITS.txt` |
| التعليق | صوت اصطناعي عربي؛ نسخة معتمدة تتضمن مقتطف لفظ الجلالة من تسجيل قرآني عبر Quran.com؛ لا ننسبه إلى قارئ غير موثق |

مواد الفيلم ورسومه للتعريف بالمشاركة ضمن نطاق المالك. لا نعطي ترخيصًا عامًا لإعادة بيع أصوات أو صور أو شعارات الغير. الحقوق الفردية للأصول لا تتغير بسبب إدراج نسخة مركبة هنا. بوابة [سلسبيل](https://salsabeel.ai/) وخدمة [برق](https://barq.salsabeel.ai/) مستقلتان عن إتاحة كود تطبيق المشاركة.


سجل روابط المصادر الـ15 المتاحة في هذه الحزمة: [source-rights-register.json](source-rights-register.json). يغطي ما نرفقه هنا فقط؛ جرد حقوق مدونة المزود الكاملة غير مثبت بهذه الحزمة. يمكن للجهة مراجعة روابط المصدر دون نسخ المدونة.

[سجل المصادر المعتمدة والاستخدام والتحقق](SOURCES_AR.md) يربط مرجعية التحدّي بالأدلة المنشورة، و[السجل الآلي](source-coverage.json) يحفظ بصمات وثائق المتطلبات وحالة التغطية. الاعتماد العلمي لا يمنح تلقائيًا حقوق النسخ أو إعادة التوزيع.
