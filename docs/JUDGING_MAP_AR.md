# خريطة المعايير والأدلة

لا تمنح هذه الخريطة المشروع درجة ذاتية. تُظهر ما يمكن فحصه الآن وما يتطلب دليلًا إضافيًا.

المنتج الحالي هو **مجلس سلسبيل: برق الفتى ولينة وقبس** بتاريخ ٦ أكتوبر ٢٠٢٦. تبقى المقارنات السابقة وتقارير المرشدين أدلة مؤرخة، ويُقيَّم المجلس على نسخه وأمثلته الحالية.
