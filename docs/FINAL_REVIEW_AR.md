## ما الجديد في النسخة الأساسية؟

ثلاث شخصيات باقتراحات وسياقات مستقلة، وبث للإجابة قبل النهاية، ومصادر واضحة للينة وقبس، وقارئ للنصوص، وأزرار إحالة من بعض ردود الفتى ترسل السؤال المرتبط بها. يبقى الانتقال بين الشخصيات باختيار المستخدم؛ لا ننسب إلى المجلس نقلًا تلقائيًا شاملًا للسياق.

| الموقع | وظيفته |
|---|---|
| [islamicaich.salsabeel.ai](https://islamicaich.salsabeel.ai/) | المجلس الثابت للتجربة والتحكيم |
| [islamicaich1.salsabeel.ai](https://islamicaich1.salsabeel.ai/) | أرشيف مستقل للتجربة السابقة |
| [islamicaich2.salsabeel.ai](https://islamicaich2.salsabeel.ai/) | التطوير؛ لا يُستخدم بدل رابط التسليم |

## مواد المجلس الجاهزة للمراجعة

الوثائق والعرض والفيلم تعرض المجلس الحالي، والدليل يضم لقطات أصلية لسؤال الكعبة وفتح مرجعه. تبقى الأمثلة السابقة موسومة بتاريخها؛ لا تُعرض على أنها تصوير لواجهة المجلس الجديد.

| المادة | الإصدار والنطاق |
|---|---|
| README ودليل المستخدم والمعمارية | محدّثة بحسب إيصال المجلس الثابت |
| صور المجلس | لقطات فعلية للاختيار والكتابة وجواب الفتى وفتح مرجع الجمهرة 92923، وقارئ الطبري، ومصادر لينة |
| PowerPoint وPDF | ١٦ شريحة للمجلس بهوية التحدي؛ لقطات الأدوات الحالية في ٨ و٩ و١١، والمشكلة والنفع في ١٣، وخطة الاستمرار والتكلفة الافتراضية في ١٥. PDF مطابق للرسوم النهائية، وكلا الملفين دون ١٠ ميغابايت |
| دليل البدء PDF | ٣ صفحات مصوّرة للاختيار والكتابة وفتح المرجع |
| الفيديو | R13، مدته ١١٨ ثانية، يضم لقطات الأدوات من المجلس الحالي ويحفظ المقدمة والعلماء والتعليق الصوتي المعتمد؛ نسختان مع الموسيقى ودونها |
| الكود | `council/` للواجهة ووحدتي الطابور وأخطاء المزوّد والمعاينة وعقد الخادم المستضاف؛ `app/` مثال API للفتى. تشغيل الشخصيات الثلاث فعليًا عبر الموقع المستضاف |

## ما الذي يبقى للمراجعة؟

| الأولوية | ما يلزم التحقق منه |
|---|---|
| دلالة الجواب | فحص إسناد كل عبارة؛ لدى قبس توسعات تحتاج ضبط نطاقها وربطها الدقيق بالمراجع |
| التكرار وصيغ جديدة | إعادة الأسئلة بصياغات مختلفة ومتابعات؛ نجاح عينة واحدة لا يكفي |
| الوزن الصرفي والتغطية | تظهر أخطاء أوزان في جواب النفس والروح وفي جدول مشتقات رشد الحالي. دليل التجاور يخص القسم الإحصائي، ودليل العد يخص الشواهد المفتوحة وحدها |
| المصادر والحقوق | استكمال جرد الطبعات والتغطية والحقوق؛ إضافة مرجع لا تثبت استيعابه كاملًا في RAG |
| التشغيل والخصوصية | اختبار الحمل أوسع من الطلب الواحد والطابور المحدود؛ تثبيت سياسة الاحتفاظ وطلب الحذف |

للمراجعة البشرية: سجّل الشخصية والسؤال حرفيًا ووقت التجربة والجواب وموضع المصدر، ثم ميّز نجاح المهمة، والجواب الجزئي، والاستيضاح أو الإحالة المناسبين، وخلل المحتوى، وخلل التنفيذ. لا تستخدم بيانات شخصية حقيقية.
