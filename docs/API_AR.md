# عقود التكامل وحدود إتاحتها

هناك نطاقان مختلفان: **مثال الفتى للمطوّر** في `app/`، و**واجهة مجلس سلسبيل الحالية** في `council/`. نشر الواجهة لا يمنح صلاحية خدمة لينة وقبس لعموم المطورين.

## ١. خدمة برق الفتى للمطوّرين

المزود: [سلسبيل — بوابة المطورين](https://barq.salsabeel.ai/developers/?lang=ar).

```http
POST https://barq.salsabeel.ai/api/developer/v1/fata/chat
Authorization: Bearer YOUR_SERVER_SIDE_KEY
Content-Type: application/json
Idempotency-Key: UNIQUE_UUID_FOR_THIS_REQUEST
Accept: application/json
```

```json
{"message":"لماذا يعبد المسلمون الكعبة؟"}
```

في المتابعة يرسل التطبيق `conversation_id` الذي أعادته الخدمة. يدعم التطبيق استقبال JSON أو `text/event-stream` بأحداث `progress` و`text` و`final` و`error`؛ راجع [كود التكامل](../app/src/server.mjs) بدل افتراض حقول غير موثقة.

المتصفح يتصل بوسيط التطبيق في `/api/chat` ولا يرى المفتاح. يعيد الوسيط استخدام معرّف الطلب عند إعادة المحاولة، ويعزل الجلسات، وينقح العرض قبل إرساله للمتصفح. قارئات المراجع تمر بمسارات محددة في [readers.mjs](../app/src/readers.mjs)؛ لا يتيح التطبيق تمرير عنوان خارجي عشوائي.

هذا وصف لاستخدام مثال `app/`، وليس وعدًا بثبات عقد المزود إلى الأبد. مخرجات الخدمة تعتمد على حسابك وحصته وصلاحياته وإصدار الخدمة الحي.

## ٢. عقد المتصفح في المجلس الثلاثي

هذا وصف للواجهة المنشورة حتى يتمكن المحكّم من فهم الربط. **هو عقد تطبيق التحدي من نفس الأصل، وليس API عامة بديلة عن بوابة المطورين.** يُجرّب عبر [الموقع الحي](https://islamicaich.salsabeel.ai/)، ولا يحتاج زائر الموقع إلى مفتاح.

| الطلب النسبي داخل الموقع | الغرض |
|---|---|
| `POST /api/access` بجسم `{}` | تهيئة جلسة الموقع؛ المفتاح يبقى على خادم المضيف، والكوكي `HttpOnly` |
| `POST /api/chat` | إرسال السؤال والشخصية ومعرّف الطلب، ومعرّف المحادثة عند المتابعة |
| `GET /api/barq/read/…` | قراءة مرجع مسموح في جلسة الموقع؛ ليس وسيطًا لعناوين خارجية عشوائية |
| `GET /api/services` | بيان إتاحة خدمات المطوّرين؛ لينة وقبس موصوفتان بـ«قريبًا» وخاصتين بتجربة التحدي |

جسم الطلب الذي يرسله [كود الواجهة الحالي](../council/public/app.js):

```json
{
  "module": "fata",
  "message": "فسر الآية 11 من سورة الحجرات",
  "request_id": "UNIQUE_UUID_FOR_THIS_REQUEST"
}
```

قيمة `module` هي `fata` أو `linah` أو `qabas`. تعيد الخدمة `conversation_id`؛ تُرسل قيمته في المتابعة للشخصية نفسها. تغيير الشخصية لا ينقل كامل تاريخ الحوار. لا تستخدم كوكي مستخدم آخر أو تعِد كتابة `Origin` لتشغيل عميل غير مخوّل.

عند قبول `text/event-stream` تتعامل الواجهة مع `progress` و`text` و`final` و`error`. يحتوي الرد النهائي على `answer`، وقد يحتوي `template` و`citations` و`elapsed_ms` و`review`. قارئ البث الفعلي في [`stream-ui.js`](../council/public/stream-ui.js)، وبناء المصادر والمراجعة في `app.js`. لا يوجد حقل مطلوب لنشر التفكير الداخلي.

إشارة اكتمال المراجعة الآلية تصف انتهاء خطوة، وليست شهادة صحة علمية. فشل الاتصال أو الحصة أو الجلسة فشل تشغيل، ولا يصنف امتناعًا معرفيًا صحيحًا. الرابط المرجعي يحتاج فحص دلالته على الجواب.

**المتاح لإعادة التشغيل:** خادم `council/preview.mjs` يخدم الملفات العامة فقط، ويعيد `503 HOSTED_COUNCIL_REQUIRED` عند استدعاء أي API. لا يحتوي خادم المجلس الإنتاجي ولا ينسخ مفتاح التحدي. لبناء تكامل خارجي للينة وقبس يلزم إعلان خدمة وعقد وصلاحيات من سلسبيل؛ لا نفترض ذلك من عملهما داخل الموقع. راجع [حدود كود المجلس](COUNCIL_SOURCE_AR.md).
