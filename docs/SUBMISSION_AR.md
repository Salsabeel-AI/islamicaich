# بيانات التسليم النهائي

## اسم المشروع

برق: الذكاء العربي الموثّق لخدمة المعرفة الإسلامية

## وصف المشروع

برق مشروع سلسبيل لخدمة الباحثين وطلبة العلم والجمهور بإجابات عربية يمكن تتبّع أدلتها. تقدّم تجربة «مجلس سلسبيل» ثلاث شخصيات: برق الفتى للقرآن والحديث واللغة وأدوات المعرفة، ولينة للحوار الفقهي، وقبس للبحث والمقارنة. يختار المستفيد شخصية، ويكتب سؤاله أو يختار سؤالًا جاهزًا، ثم يقرأ الإجابة ويفتح مصادرها، مع محادثة مستقلة لكل شخصية.

يوظّف المشروع الذاكرة النصية المهيكلة NMN لضبط الاستشهاد، والتجاور القرآني لاستكشاف قرائن الاستعمال، وأدوات تربط الأعداد بالشواهد، إضافة إلى حسابات تعليمية مثل الفرائض. يعرض التسليم المعمارية وأدلة RAG والتضمين والتخصيص وعينات الاختبار وحدودها. تعمل خدمات النماذج لدى سلسبيل بوصفها مزوّد API، ويضم المستودع كود التطبيق المسموح بنشره ووثائقه، مع تمييز المعرفة العامة عن الحالات التي تحتاج إلى مختص.
