# حزمة GitHub الأولى — ٥ أكتوبر ٢٠٢٦

الحزمة مأخوذة بقائمة ملفات مسموحة من التطبيق ومواد العرض والأدلة. لم يُنسخ تاريخ مستودعات داخلية أو ملفات بيئة أو سجلات زوار أو قواعد بيانات أو أوزان. نتائج التحقق الآلي في `evidence/release-checks.json`، وبصمات الملفات في `MANIFEST_SHA256.json`.

تغييرات التغليف: تحويل مسار استيراد اختبار إلى مسار نسبي، حذف المسارات المحلية من بيانات النسب، إعداد نموذج بيئة فارغ، وإضافة وثائق المحكّم والبطاقات واللقطات ومصادر تركيب الفيلم. التطبيق الإنتاجي لم يتغير بسبب عملية التغليف.

لفحص سلامة الملفات: `python scripts/verify_manifest.py`. لتجميع ملخص التشغيل من النتائج المنشورة: `python scripts/summarize_evaluation.py`. الاختبارات داخل `app` تستخدم بدائل خدمة مصطنعة؛ نجاحها لا يثبت جودة جواب المزود الحي.

لم يُغيّر هذا التسليم خصوصية المستودع. الأدلة غير المكتملة (جرد المصادر الشامل، top-100، وحزمة الموجة الثالثة) معلنة ولا تُستبدل بأرقام مختلقة. تُقدّم ملفات العرض الحديثة في الموقع، أما إصدارات PPTX/PDF القديمة ذات الصياغات السابقة فلا تُضمّن تلقائيًا كنسخة نهائية معتمدة.
