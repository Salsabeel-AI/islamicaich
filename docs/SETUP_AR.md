# تشغيل مواد التسليم والحصول على مفتاح الخدمة

## تجربة المجلس الحالي دون إعداد محلي

افتح [مجلس سلسبيل](https://islamicaich.salsabeel.ai/) للشخصيات الثلاث، أو [دليل المحكّم](https://islamicaich.salsabeel.ai/judge-guide.html). لا يحتاج زائر التحدي إلى مفتاح. هذه هي نسخة المنتج الحالية؛ دليل التشغيل التالي يفصل معاينة واجهتها عن مثال تكامل الفتى السابق.

## معاينة الواجهة الحالية محليًا

بعد تثبيت Node.js 22 أو أحدث:

```sh
cd council
npm start
```

افتح `http://127.0.0.1:8793`. لا تثبيت حزم ولا ملف أسرار مطلوبان. شغّل `npm test` و`npm run check` داخل `council` لفحص التصدير. يمكنك اختيار الشخصيات واستعراض الأسئلة؛ توليد الإجابات وقارئات المراجع يستلزمان الخدمة الحية. الصفحة المحلية تبيّن هذا القيد، وطلبات API المحلية تعيد خطأ `HOSTED_COUNCIL_REQUIRED`؛ لا توجد إجابات وهمية.

هذه معاينة لكود المتصفح المطابق للنسخة المثبتة، **وليست نسخة مستقلة من خادم المجلس الثلاثي**. مصدرها وبصماتها في [`council/provenance.json`](../council/provenance.json). اطلع على [حدود النشر](COUNCIL_SOURCE_AR.md) و[عقود التكامل](API_AR.md).

## تشغيل مثال تكامل برق الفتى بمفتاح مطوّر

المجلد `app/` يحتفظ بالبوابة السابقة كمثال تكامل مستقل؛ لا يضيف لينة وقبس إلى حساب المطوّر ولا يطابق واجهة المجلس الحالية. لا يلزم تشغيله لتجربة الموقع الحي.

1. افتح [بوابة مطوري سلسبيل](https://barq.salsabeel.ai/developers/?lang=ar)، وسجّل الدخول بحساب مخوّل.
2. أنشئ مفتاح API يتيح خدمة برق الفتى عندما تكون الخدمة متاحة لحسابك. الاستحقاق والحصة والصلاحيات يحددها المزود؛ لا تفترض حصة مفتوحة أو مجانية.
3. ثبّت Node.js 22+ ثم نفّذ `npm ci` داخل `app`.
4. انسخ `.env.example` إلى `.env`. ضع المفتاح في `SALSABEEL_API_KEY` **على الخادم فقط**، أو استخدم `SALSABEEL_API_KEY_FILE` لمسار ملف خاص خارج المستودع.
5. شغّل `npm start` وافتح `http://127.0.0.1:8791`.

الاختبارات لا تحتاج اتصالًا بالمزود: `npm test` ثم `npm run check` داخل `app`. ملفات الفيديو متضمنة في `app/public/beta/2-5`، وصفحة المشاهدة المحلية في `/beta/2-5/`.

| الإعداد | وظيفته |
|---|---|
| `PORT` / `HOST` | الافتراضي 8791 و127.0.0.1 |
| `PUBLIC_ORIGIN` | أصل المتصفح الكامل عند النشر خلف HTTPS، بلا مسار أو شرطة أخيرة |
| `SESSION_ANSWER_LIMIT` | الحد المحلي للجلسة؛ الافتراضي 10، والصفر غير محدود محليًا فقط |
| `QUEUE_CONCURRENCY` | عدد الطلبات المتزامنة محليًا؛ الافتراضي 4، ولا يوسّع حصة المزود |

`GET /health` يبيّن جاهزية الإعداد المحلي، وليس ضمانًا لصحة المفتاح لدى المزود. إذا ظهر `configured:false` راجع إعداد المفتاح. أخطاء الصلاحية أو الحصة أو انشغال الخدمة تظهر برسالة واضحة، ولا تُحتسب جوابًا أو امتناعًا معرفيًا.

تاريخ المحادثة في ذاكرة العملية ومؤقت. يولّد تطبيق التشغيل سجل زيارات خاصًا لصفحات التقارير (قد يشمل IP وتصنيف المتصفح؛ احتفاظ 30 يومًا) خارج الملفات العامة في `private/report-analytics`؛ لا تُرفق أي سجلات فعلية بالتسليم. راجع سياسة الجهة المستضيفة قبل تشغيله لزوار حقيقيين. الخدمة المستضافة تستقبل نص السؤال لتنتج الجواب.
